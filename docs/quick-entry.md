# 콘텐츠 간편 입력

확인일: 2026-10-30 (KST). [텐타시현 SOOP 방송국](https://www.sooplive.com/station/xxxsihyeon)의 공개 방송공지와 다시보기를 참고해 일정 작성용 버튼을 제공합니다.

## 사용 방법

1. **일정 편집**에서 날짜를 고릅니다.
2. **콘텐츠 간편 입력**의 시작 시간을 정합니다. 처음에는 기존 일정 입력과 같은 `20:00`이며, 빈칸으로 두면 시작 시간 미정으로 추가합니다.
3. 콘텐츠 버튼을 누르면 선택한 날짜에 **새 일정**이 추가됩니다. 제목·시간·설명은 일정 카드에서 자유롭게 수정합니다. 기존 일정은 덮어쓰지 않습니다.

기본 항목은 **안듣텐, 텐해줘, 시네티, 노래뱅, 월드컵, 종합게임, 휴방**입니다. 휴방은 휴방 상태로 추가되고 시간을 비워 둡니다. 하루에 여러 콘텐츠를 추가할 수 있으며 기존과 같은 6개 제한을 적용합니다. 추가는 Ctrl+Z로 취소할 수 있습니다.

간편 입력의 제목은 편집용 예시입니다. SOOP의 확정된 미래 일정을 자동으로 불러오거나, 특정 요일·방송 시각을 추정하지 않습니다. 앱 실행 시 SOOP에 자동 접속하지 않으며, 방송국 링크는 사용자가 직접 열 수 있습니다.

## 내 콘텐츠 저장

1. 일정 카드에서 자주 쓸 제목·설명·방송/휴방/미정 상태를 입력합니다.
2. 카드 아래 **내 콘텐츠로 저장**을 누릅니다.
3. 간편 입력의 **내 콘텐츠**에서 다시 눌러 다른 날짜에도 추가합니다. 방송은 간편 입력에 표시된 시작 시간을 사용합니다. 이전 방송의 시작/종료 시각은 콘텐츠 항목에 복사하지 않습니다.

- 현재 프로젝트마다 최대 24개를 저장합니다. 제목·설명·상태가 같은 항목은 중복 저장하지 않습니다.
- 해당 프로젝트의 다른 주에도 사용할 수 있습니다. 새로운 별도 프로젝트와는 목록을 공유하지 않습니다.
- 항목 옆 ×로 삭제할 수 있고 Ctrl+Z로 되돌릴 수 있습니다. 이름이나 내용을 바꾸려면 일정 카드에서 수정한 내용을 새로 저장하고 이전 항목을 삭제합니다.
- **내 콘텐츠는 프로젝트 자동 저장, 최근 저장, `.tssproj` 백업·복원에 함께 포함**됩니다. 사이트 데이터를 지우기 전에는 백업 파일을 보관하세요.
