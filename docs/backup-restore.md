# 백업·복원 가이드

앱 왼쪽 아래 **백업 가이드**, 상단 **프로젝트 이름 ⌄ → 백업·복원 가이드**, 또는 **사용 안내 → 백업·복원 가이드**에서 같은 안내를 볼 수 있습니다. 안내 창의 버튼으로 바로 백업하거나 복원 파일을 선택할 수도 있습니다.

## 백업 파일 저장

1. 백업할 프로젝트를 엽니다.
2. 왼쪽 아래 **백업** 또는 상단 **프로젝트 이름 ⌄ → 프로젝트 백업**을 누릅니다.
3. `SIHYEON_YYYY-MM-DD.tssproj` 파일이 다운로드될 때까지 기다립니다. 파일 위치는 브라우저의 다운로드 목록에서 확인합니다.
4. PC의 보관 폴더에 파일을 저장합니다. 수정한 뒤에는 새 백업을 내려받습니다. 이미 받은 파일에 이후 수정이 자동 반영되지는 않습니다.

백업 한 개에는 **현재 선택한 프로젝트의 주간 일정, 업로드 이미지, 템플릿과 디자인 배치, 내 콘텐츠 목록**이 함께 들어갑니다. 프로젝트가 여러 개라면 각각 열어서 백업하세요.

## 백업 파일 불러오기

1. [SIHYEON STUDIO](https://tenta-scheduler.ryan9320.workers.dev)를 엽니다. 첫 안내가 보이면 **이번 주 만들기**를 누릅니다.
2. 상단 왼쪽 **프로젝트 이름 옆 ⌄**을 누릅니다.
3. **프로젝트 복원**을 선택합니다.
4. PC에 보관한 `.tssproj` 파일을 선택합니다. 파일의 압축을 풀거나 확장자를 바꿀 필요는 없습니다.
5. 확인 창의 프로젝트 이름과 이미지 수를 확인한 뒤 **복원하기**를 누릅니다.
6. 이미지·일정·배치를 확인합니다. 복원한 파일은 새 프로젝트 사본으로 열리고, 이전 작업은 **프로젝트 열기** 목록에 유지됩니다.

안내 창에서 **복원 파일 선택**을 눌러 4번 단계부터 시작할 수도 있습니다.

## 자동 저장, PNG와의 차이

| 종류 | 저장되는 내용 | 다시 편집 |
| --- | --- | --- |
| 브라우저 자동 저장 | 지금 사용하는 브라우저·주소의 작업 내용 | 같은 브라우저·주소에서 가능 |
| `.tssproj` 백업 | 프로젝트 일정·이미지·디자인을 담은 PC 파일 | 프로젝트 복원으로 가능 |
| `.png` 출력 | 공유용으로 완성된 이미지 한 장 | 프로젝트로 복원할 수 없음 |

현재 자동 저장은 온라인 저장이 아닙니다. 사이트 데이터를 삭제하면 작업과 **최근 저장 복구** 기록도 함께 지워질 수 있습니다. 사이트 데이터 삭제 전, PC·브라우저 변경 전, 로컬 주소에서 배포 주소로 이동하기 전에 백업하세요.

## 파일이 보이지 않거나 복원되지 않을 때

- 브라우저 다운로드 목록에서 `.tssproj` 파일의 저장 위치와 다운로드 완료 여부를 확인합니다.
- 파일 선택 창에서는 PNG나 일반 ZIP 대신 원래 내려받은 `.tssproj` 파일을 선택합니다.
- 손상되거나 지원하지 않는 버전의 백업은 오류 안내가 표시됩니다. 원본 파일을 다시 복사하거나 다른 백업을 선택합니다.
- 이미지까지 보관하려면 PNG 출력과 별도로 프로젝트 백업을 저장해야 합니다.
