# Design system

Editor colors: background `#15161D`, panel `#24232F`, accent `#802D4B`, secondary `#D7CBD0`, text `#F8EFF2`. Borders are translucent warm grey, cards have 10–16 px radii, controls 7–9 px. Accent rose is reserved for current state and primary actions. Keyboard focus uses a visible rose outline.

UI typography: local Windows Malgun Gothic / Segoe UI. Canvas typography uses bundled-by-OS Georgia and Malgun Gothic. No network font dependency. Body 12–14 px, section titles 14 px, brand 17 px. Lucide 16–20 px outline icons.

Structure: 64 px top bar, 68 px tool rail, 300 px tool panel, flexible central viewport, 264 px inspector, 36 px footer. At narrow desktop width, panels reduce to 272 / 236 px. Panels scroll internally; controls never cover the canvas footer.

Burgundy Academy: oxblood paper, black uniform tones, silver-white typesetting and piping, twin silver/burgundy hair-inspired lines, a red geometric gem and silver chain motifs. Expelled Magic Journal: ivory paper, graphite ink, red annotations, ledger rules and celestial geometry. Decorative seals are original abstract shapes, never official assets. Two user-selected screenshots are retained unmodified in the optional image collection; adding one decodes it into a Blob asset.
