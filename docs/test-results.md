- Edge 브라우저 통합 테스트 **18/18 통과**.

- 100개 요소 비교 측정은 [보완 결과](improvement-status.md)에 수록. 조건별 메인 스레드 시간 중앙값 1805 → 193 ms.
- GitHub Actions는 Ubuntu Chromium 검증을 실행하도록 구성했습니다. 이 문서의 통과 수치는 로컬 Windows Edge 결과이며 원격 CI 결과를 대신하지 않습니다.

## 알려진 제한

하루 6개 일정, 제목 240자, 설명 300자, 디자인 100개, 이미지 15 MB/8192 px, 프로젝트 120 MB 제한이 있습니다. 과도하게 많은 긴 내용은 글자가 작아집니다. OS 기본 폰트를 사용하며, 모바일 최적화·클라우드 동기화·스냅샷 선택 UI·미사용 이미지 저장소 정리는 제공하지 않습니다. 상세 사용 범위는 README를 참고하세요.
