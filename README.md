# SIHYEON STUDIO v1.1.2

텐타시현을 위한 **주간 방송 스케줄 디자인 편집기**입니다. Windows PC 브라우저에서 일정 작성부터 자유 배치, 로컬 저장, 1920×1080 PNG 출력까지 사용할 수 있습니다.

저장소: [gamsung0388/tenta_scheduler](https://github.com/gamsung0388/tenta_scheduler). Cloudflare에 올리는 방법은 [배포 가이드](docs/deployment-cloudflare.md), 보완 내역은 [변경 기록](CHANGELOG.md)을 참고하세요.

## 빠른 실행

Node.js **20.19 이상인 20.x / 22.12 이상 / 24.x**가 필요합니다. 검증 환경은 Windows, Node.js 24.11.1, Microsoft Edge입니다.

설치본의 `START-STUDIO.cmd`를 더블클릭하거나 PowerShell에서 실행합니다.

```powershell
cd E:\tenta
npm.cmd ci
npm.cmd run dev -- --port 5173 --strictPort
```

브라우저에서 **http://127.0.0.1:5173/** 을 엽니다. 설치본에 의존성이 포함된 경우 `npm.cmd ci`는 생략할 수 있습니다. 최초 패키지 설치에만 인터넷이 필요하며, 앱은 외부 폰트·이미지·API 없이 동작합니다.

같은 브라우저 프로필과 같은 주소·포트를 사용해 주세요. `localhost`, `127.0.0.1`, 다른 포트는 서로 다른 브라우저 저장 공간입니다. `index.html`을 파일로 직접 여는 방식은 지원하지 않습니다. Vite는 정적 파일을 제공하는 개발 도구이며 앱용 백엔드는 없습니다.

## 사용 흐름

1. **일정**에서 날짜와 요일을 고르고 일정을 추가합니다. 방송·휴방·미정, 제목, 시작·종료 시간, 설명을 입력하면 즉시 미리보기에 반영됩니다.
2. **템플릿**에서 Burgundy Academy 또는 Expelled Magic Journal을 고릅니다. 주간 일정과 사용자 배치를 유지하며 색과 장식이 바뀝니다.
3. **이미지**에서 PNG/JPG/WEBP를 업로드하거나 사용자 제공 참고 이미지 2종을 선택합니다. 추가한 이미지는 별도 Blob으로 저장됩니다.
4. **디자인 편집**에서 요소를 선택하고 이동·크기 조절·회전합니다. 오른쪽 속성에서 정확한 좌표, 크기, 폰트, 색상, 정렬 등을 조절합니다. **레이어**에서 숨긴 요소도 선택할 수 있습니다.
5. **PNG 다운로드**로 1920×1080 파일을 받습니다. 화면 줌, 안전 영역, 선택선과 Transformer는 출력되지 않습니다.
6. 왼쪽 하단 **백업** 또는 상단 프로젝트 메뉴에서 이미지 포함 `.tssproj`를 저장합니다. **프로젝트 복원**은 새 사본을 만들고 기존 프로젝트도 보관합니다.

일정표의 글꼴은 **일정 편집 → 오른쪽 일정표 폰트 → 글꼴**에서 변경합니다. 디자인 모드에서 **주간 일정표**를 선택해도 같은 설정이 표시됩니다. 요일·날짜·시간·제목·설명에 함께 적용되며, **템플릿 기본**을 선택하면 원래 글꼴 조합으로 돌아갑니다. 새로고침·템플릿 변경·백업 복원·PNG 출력에도 선택한 글꼴이 유지됩니다.

처음 실행하면 현재 주와 기본 템플릿이 표시됩니다. 주간은 월요일 시작이며 다음 주 생성 시 디자인을 유지하고 일정을 기본적으로 비웁니다. 생성 창에서 ‘방송 일정도 함께 복사’를 선택할 수 있습니다. 프로젝트 메뉴의 **프로젝트 열기**에서 이전 작업과 복원 사본을 전환하거나 새 프로젝트를 만들 수 있습니다.

## 백업과 복원

- **백업:** 왼쪽 아래 **백업** 또는 상단 **프로젝트 이름 ⌄ → 프로젝트 백업** → `.tssproj` 파일을 PC에 보관합니다. 현재 프로젝트의 일정·이미지·디자인이 함께 저장됩니다.
- **복원:** 상단 **프로젝트 이름 ⌄ → 프로젝트 복원** → `.tssproj` 선택 → **복원하기**. 기존 작업을 유지하고 새 사본으로 엽니다.
- **앱 안의 안내:** 왼쪽 아래 **백업 가이드**, 프로젝트 메뉴 또는 **사용 안내**에서 백업·복원 가이드를 열 수 있습니다. 안내 안에서도 백업/복원을 바로 실행합니다.

PNG는 공유용 이미지이며 편집 가능한 프로젝트로 복원할 수 없습니다. 사이트 데이터 삭제·PC/브라우저 변경·주소 이동 전에 `.tssproj`를 저장하세요. 자동 저장과 최근 저장 복구는 현재 브라우저 안에만 보관됩니다. 상세 절차는 [백업·복원 가이드](docs/backup-restore.md)를 참고하세요.

## 실제 구현한 기능

- 월요일 시작 날짜 계산, 이전·다음 주 및 날짜 선택, 복수 방송, 휴방·미정, 실시간 미리보기
- 내용량에 따른 요일별 높이 배분, 3열/복수 행 일정 배치, 긴 제목·설명의 줄바꿈과 글자 크기 자동 맞춤
- 일정 모드에서 캔버스 이동 차단; 디자인 모드의 선택, 드래그, Transformer 크기 조절 및 회전
- 좌표·크기·회전 숫자 편집, 이미지 비율 유지, 레이어 순서, 잠금 및 표시·숨김
- 텍스트 추가, 내용·폰트·크기·색상·굵기·정렬 편집; 일정표 전체의 폰트 변경
- 원본 1920×1080 좌표와 화면 줌 분리, 화면에 맞춤, 미리보기 전용 안전 영역
- Pinia 프로젝트/일정/에디터 스토어 분리, 실행 취소/다시 실행 70단계, 800 ms 디바운스 자동 저장
- Dexie의 `projects`, `assets`, `snapshots`, `preferences`; 이미지 Blob/assetId 연결, Object URL 수명 관리
- 저장 중·완료·실패 표시, 재시도, 저장 공간 부족·손상 이미지·파일/폰트 로딩 오류 처리
- 이미지·폰트 준비 후 별도 원본 배율 Konva Stage에서 PNG 렌더링
- schemaVersion이 포함된 ZIP 백업·복원, 구조/파일 서명/CRC 검증, 누락 이미지와 버전 불일치 안내
- 두 템플릿, 첫 사용 안내, 빈 상태, 키보드 포커스, 모달 내 포커스 이동, PC 패널 내부 스크롤

### v1.1 보완

- 편집·저장·복원의 좌표와 크기 규칙을 통일했습니다. 작은 이미지와 캔버스 밖 배치도 복원 후 유지합니다.
- 제목 18 px, 설명 12 px를 기준으로 공간을 점검합니다. 들어가지 않는 글은 출력 전 점검에서 수정하거나 **넘치는 글 요약 허용**을 명시적으로 선택합니다. 원문은 그대로 저장합니다.
- 상단 프로젝트 메뉴의 **최근 저장 복구**에서 프로젝트별 최대 10개 상태를 미리 보고 새 사본으로 복구합니다. 최초 저장과 이후 30초 이상 지난 변경을 보관합니다.
- 초기 로딩 중 편집을 차단합니다. 다른 탭에서 수정하면 저장 버전 비교와 알림으로 덮어쓰기를 막고 **현재 작업 사본 저장 / 최신 버전 열기**를 제공합니다.
- 캔버스 요소·일정 행 재사용, 텍스트 측정 캐시, 프레임 단위 갱신 병합, 변경분 Undo 기록을 적용했습니다.
- 이미지 미리보기는 최대 768 px로 만들고 출력 시 원본을 다시 읽습니다. 이미지 Blob은 새로 추가되거나 교체된 경우에만 저장합니다.
- **미사용 이미지 정리**는 모든 프로젝트, 최근 저장, 현재 Undo/Redo에서 사용하는 자산을 보호합니다.
- 방송 복제·순서 변경·하루 복사/추가, 다음 날 종료 표기, 요소 복제·레이어 이름·중앙 정렬·방향키 이동·스냅·캔버스 안 맞춤을 추가했습니다.
- 이미지 교체와 **프레임 채우기·자르기 위치**를 제공합니다. 원본 파일을 변경하지 않습니다.
- 출력 점검에서 넘치는 텍스트·누락 이미지·작은 글자·캔버스 밖 배치를 안내하고, 템플릿 썸네일도 실제 출력 렌더러로 만듭니다.

## 시현 참고 이미지와 템플릿

사용자가 선택한 제복 클로즈업과 장면 스크린샷 2장을 `public/references/`에 원본 그대로 포함했습니다. 이미지 패널의 **사용자 제공** 섹션에서 선택해 사용할 수 있습니다. 새 프로젝트의 캔버스에는 선택 시 추가됩니다. 공식 로고나 일러스트를 새로 생성하지 않았습니다.

- **Burgundy Academy**: 투톤 헤어를 연상시키는 은백색/버건디 선, 검정 제복, 은색 테두리, 붉은 보석과 체인에서 착안한 추상 장식.
- **Expelled Magic Journal**: 은백색·아이보리 종이, 붉은 주석, 기록부 줄과 달 문양.

템플릿 문양은 이 앱을 위해 만든 추상적인 도형입니다. 참고 스크린샷의 권리는 원 권리자에게 있으며 앱 소스의 자체 작성 코드와 구분됩니다.

## 빌드와 정적 배포

```powershell
npm.cmd run build
npm.cmd run preview -- --port 4173
```

`dist/` 내용 전체를 정적 호스팅에 업로드하면 됩니다. 상대 경로 기반으로 빌드하며 앱용 백엔드·로그인·D1은 사용하지 않습니다. 현재 서비스는 [Cloudflare Workers Static Assets](https://tenta-scheduler.ryan9320.workers.dev)에 배포되어 있습니다. 배포된 도메인의 브라우저 저장 공간은 로컬 개발 주소와 별개이므로 `.tssproj` 백업으로 옮겨 주세요.

## 테스트

```powershell
npm.cmd test
npm.cmd run test:browser
```

브라우저 테스트는 기본 Windows Edge 설치 경로를 사용합니다. 다른 경로는 `$env:EDGE_PATH`로 지정할 수 있습니다. 개발 서버가 없으면 자동으로 실행합니다. 실제 결과는 `docs/test-results.md`에 정리했습니다.

## 제한과 미완성 범위

요청한 v1 핵심 작업 흐름은 구현되어 있습니다. 다음은 지원 범위와 알려진 제한입니다.

- 하루 최대 **6개 일정**, 일정 제목 **240자**, 설명 **300자**, 디자인 요소 **100개**, 프로젝트당 **520주**입니다. 모든 내용을 읽을 수 있는 크기로 담기 어려우면 출력 점검에서 알려줍니다. 요약 허용 시 표시만 줄이며 원문은 유지합니다.
- 이미지 한 장 **15 MB**, 각 변 **8192 px**, 백업 파일 **120 MB** 제한이 있습니다. SVG·GIF·외부 이미지 URL과 웹 폰트 업로드는 지원하지 않습니다.
- 복원 가능한 백업의 압축 해제 총량은 120 MB, manifest는 3 MB입니다. PNG 원본 이미지 로딩은 메모리 관리를 위해 합계 96 MP까지 지원합니다.
- 폰트는 PC에 설치된 맑은 고딕, 바탕, 돋움, 굴림, 궁서, Georgia, Segoe UI, Arial을 사용합니다. 해당 글꼴이 없는 PC·OS에서는 대체 폰트로 표시되며 줄바꿈이 달라질 수 있습니다. 폰트 파일 업로드·번들은 아직 지원하지 않습니다.
- 템플릿 배경·장식은 고정되어 있고 일정표는 하나의 편집 그룹입니다. 일정 내용은 일정 패널에서 관리합니다. 자유 곡선·도형 그리기, 개별 일정 카드의 수동 분리는 v1 범위에 없습니다.
- 저장은 해당 브라우저의 IndexedDB입니다. 다른 기기 동기화·클라우드 저장은 없으며, 시크릿 모드·사이트 데이터 삭제 시 유실될 수 있으므로 `.tssproj` 백업을 권장합니다.
- Undo 기록은 현재 실행 세션에서 최대 70단계 유지됩니다. 최근 저장 복구는 프로젝트마다 최대 10개를 보관합니다. 미사용 이미지는 다른 프로젝트·복구·Undo 기록에서 참조하지 않을 때 정리됩니다.
- Windows Edge에서 검증했습니다. PC 최소 1366×768을 대상으로 하며 모바일/터치는 별도 최적화하지 않았습니다.
